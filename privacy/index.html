Privacy

Draft privacy notice for review — data handling for the marketing website and separate application.

Before public launch: the operator must provide its legal identity, contact details, hosting and logging practices, retention periods, and applicable rights process. This draft does not establish those facts.

This marketing website

This implementation includes no analytics scripts, advertising pixels, contact forms, authentication, or application document uploads. Hosting infrastructure may process requests and logs; the operator must describe those practices in the final policy.

The separate application

The inspected local Knowdexia application persists documents and indexes on the computer running it. When an external AI provider is configured, questions and selected source passages can be sent to that provider. The operator must disclose the actual deployment configuration and provider policies before offering a hosted service.

Questions and data requests

An operator contact and any applicable request procedures must be added before this policy is finalized.
