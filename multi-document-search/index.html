MULTI-DOCUMENT SEARCH

One question. More than one document.

Useful answers often live across several files. Multi-document search retrieves passages from a set of documents instead of restricting every question to a single upload.

Choose the scope of your question

Search the entire library for a broad investigation. Select a collection for a project, choose a set of documents for comparison, or narrow to one document when you already know where to look.

Bring relevant passages together

Knowdexia ranks passages across the selected scope. With a configured AI provider, the answer can combine information from multiple retrieved documents and cite the passages it uses. It does not necessarily read every page of every file for each question.

Check each source independently

A cross-document answer should still be traceable to individual evidence. Follow its citations to inspect each passage, check dates and assumptions, and identify differences that need closer review.

Searchable knowledge stays useful when you can inspect its sources. Explore the interactive citation example.
